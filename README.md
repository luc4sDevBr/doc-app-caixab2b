# API de Integração Comercial — Caixa B2B

Documentação da API de Integração Comercial (Focare), gerada com [Rhyla](https://rhyladoc.com/).

## Rodar local

```
npm install
npm run dev      # prévia em http://localhost:3333
npm run build    # site estático em dist/
```

## Onde editar

- `rhyla-docs/body/*.md` — páginas
- `rhyla-docs/config.json` — título e menu lateral
- `rhyla-docs/styles/` — cores e estilos
- `rhyla-docs/public/` — logo, ícone e coleção do Postman

## Publicação

Vercel: build `npm run build`, saída `dist` (ver `vercel.json`). Cada push na `main` publica de novo.
